# Piecewise Functions

A Piecewise function is a function defined by multiple expressions, each associated with a condition. When a condition is satisfied, the equivalent expression will determinate the value of $y$ (or $f(x)$, a.k.a the function).

Here is an example:

$$
f(x) = 
\begin{cases}
-x & \text{if } x < 0 \\
x & \text{if } x \ge 0
\end{cases}
$$
